# 📊 Estudos SQL — Banco de Dados de Funcionários

## 📌 Sobre o projeto

Projeto desenvolvido para praticar comandos SQL utilizando o MySQL Workbench. Foi criado um banco de dados para gerenciar informações de funcionários, como nome, cargo, departamento, salário e data de admissão.

## 🛠️ Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL

## 🗄️ Estrutura do banco de dados

Banco de dados: `funcionarios`

Tabela: `Funcionarios`

| Coluna | Tipo de dado |
|---|---|
| id | INT |
| nome | VARCHAR(100) |
| cargo | VARCHAR(50) |
| departamento | VARCHAR(50) |
| salario | DECIMAL(10,2) |
| data_admissao | DATE |

## 📚 Conteúdos praticados

- `CREATE DATABASE` e `CREATE TABLE`
- `INSERT INTO`
- `SELECT` e `WHERE`
- `ORDER BY`
- `LIKE` e `BETWEEN`
- `DISTINCT`
- `GROUP BY` e `HAVING`
- Funções de agregação: `SUM()`, `AVG()`, `COUNT()`, `MAX()` e `MIN()`
- Subconsultas
- `CASE WHEN` para classificação salarial
- `UPDATE` para atualização de salários
- `DELETE` para exclusão de registros

## 🎯 Objetivo

Praticar consultas SQL, filtros, agrupamentos, cálculos e manipulação de dados, desenvolvendo conhecimentos em banco de dados e análise de dados.
